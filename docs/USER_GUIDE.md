## 🚀 빠른 시작 (5분)

### Step 1. Anthropic API 키 발급

1. [console.anthropic.com](https://console.anthropic.com) 가입
2. 상단 **API Keys** 메뉴
3. **Create Key** → 이름 입력 → 생성
4. `sk-ant-api03-...` 형태 키 복사
5. 결제 수단 등록 ($5 충전 권장)

> 🔒 API 키는 본인 브라우저에만 저장되며 외부 서버로 전송되지 않습니다.

### Step 2. 앱 접속 & 비밀번호 설정

1. [https://jwaytools.com/paperclip/app.html](https://jwaytools.com/paperclip/app.html) 접속
2. 처음 접속 시 비밀번호 4자 이상 설정 (로컬 잠금용)
3. 로그인

### Step 3. API 키 입력

1. 왼쪽 사이드바 **⚙️ 설정**
2. **API 설정** 섹션에 키 붙여넣기
3. **💾 설정 저장**

### Step 4. 팀 만들기 (2가지 방법)

#### 방법 A: 퀵 실행 (추천 - 30초)

1. **📊 대시보드** 이동
2. "무엇을 하고 싶으세요?" 입력란에 아이디어 입력
   - 예: "반려동물 건강 관리 앱"
   - 예: "직장인 부수입 플랫폼"
   - 예: "1인 창업가용 CRM"
3. **🚀 실행** 클릭
4. AI가 6명 팀 + 프로젝트 + 이슈 자동 생성

#### 방법 B: 검증된 템플릿 가져오기

1. [templates/](https://github.com/JaeWoo0317/jway-paperclip/tree/main/templates) 폴더에서 JSON 다운로드:
   - `01-startup-mvp-team.json` — 스타트업 MVP 6인 팀
   - `02-ecommerce-growth-team.json` — 이커머스 그로스 5인 팀
   - `03-content-creator-team.json` — 콘텐츠 크리에이터 4인 팀
2. 앱 내 **⚙️ 설정** → **📦 템플릿 가져오기**
3. JSON 파일 업로드

### Step 5. 협업 Heartbeat 실행

1. 왼쪽 **💓 Heartbeat** 이동
2. 상단 **🤝 협업** 버튼 클릭 (2라운드 기본)
3. 3~8분 대기 (매니저 → 실무자 → 매니저 검토)
4. 완료 시 **📎 아티팩트**에서 결과 확인

## 🧩 주요 개념

### 에이전트 (Agent)
- 역할별 AI 전문가 (CEO, CTO, PM, Engineer, Marketer, Designer 등 11개 역할)
- 각자 고유한 시스템 프롬프트, 역량, 모델 설정

### 하네스 (Harness)
- Anthropic 공식 패턴으로 AI 출력을 3단계로 검증
  - Gate 1: JSON 파싱 검증
  - Gate 2: 액션 유효성 검증 (이슈 존재 여부, 상태 전이 등)
  - Gate 3: 최대 3회 재시도

### Advisor Strategy
- Haiku/Sonnet (executor)이 작업하다가 어려운 판단에 Opus (advisor) 자문
- 비용 효율 극대화 (Opus 혼자 쓰는 것의 1/5 수준)

### 협업 Heartbeat
- **라운드 1**: 매니저 검토 → 실무자 실행
- **라운드 2**: 매니저 피드백 → 실무자 반영 → 완료
- `reportsTo` 관계 기반 자동 실행 순서

### 아티팩트 (Artifact)
- 에이전트가 생성하는 **실제 파일**
- 타입: `html`, `css`, `js`, `json`, `markdown`, `code`, `text`
- 이슈별로 저장 + 버전 관리

## 💰 비용 최적화

### 모델별 예상 비용 (6명 팀 + 2라운드)

| 모델 조합 | 비용 | 추천 용도 |
|----------|------|---------|
| Haiku 4.5 단독 | $0.20 ~ $0.40 | 단순 반복 작업, 운영 자동화 |
| **Haiku + Opus Advisor** | **$0.50 ~ $1.00** | **🌟 기본 추천** |
| Haiku + Advisor + 웹검색 | $0.80 ~ $1.50 | 시장 조사, 경쟁 분석 |
| Sonnet 4.6 + Advisor | $1.50 ~ $3.00 | 품질 우선, 복잡한 기획 |
| Opus 4.6 단독 | $3.00 ~ $5.00 | 최고 품질, 중요 프로젝트 |

### 비용 절감 팁

1. **기본은 Haiku + Advisor**로 시작
2. **웹검색은 필요한 에이전트에만** 활성화 (분석가/마케터 위주)
3. **Advisor는 리더 에이전트에만** (CEO, PM) 활성화
4. **이슈 코멘트가 쌓이면 비용 증가** → 주기적으로 이슈 완료 처리
5. **자동 스케줄은 매시간이 아닌 일 1회**로 시작

### Rate Limit 회피

무료 tier는 분당 50,000 입력 토큰 제한:
- **에이전트 간 지연 10~15초** 설정 (Heartbeat 페이지)
- 팀 크기 5명 이하
- 협업 라운드 2 이하

## ❓ 자주 묻는 질문

### Q. API 비용은 누가 부담하나요?
A. 본인 Anthropic API 키로 직접 호출되므로 본인이 부담합니다. 첫 실행 $0.5~$2, 월 예산 $10~20 권장. 데이터는 브라우저에만 저장됩니다.

### Q. 에이전트가 complete를 안 해요
A. 시스템에 "의사결정 원칙"이 내장되어 있습니다. 여전히 망설이면 Heartbeat 실행 시 지시사항에 "반드시 complete 처리"라고 명시하세요.

### Q. Rate limit 에러가 나요
A. 에이전트 간 지연을 10~15초로 설정하거나, 팀 크기를 5명 이하로 줄이세요. 무료 tier는 분당 50K 토큰 제한.

### Q. 협업이 몇 분 걸리나요?
A. 6명 × 2라운드 기준 약 3~8분. 모델과 웹검색 여부에 따라 달라집니다.

### Q. 데이터 백업은?
A. **⚙️ 설정 → 📥 전체 백업 (JSON)**으로 전체 데이터를 JSON 파일로 저장. 다른 기기/브라우저에서 **📤 백업 가져오기**로 복원.

### Q. 팀원과 공유할 수 있나요?
A. 현재 버전은 단일 사용자용. 팀 협업이 필요하면 **📥 데이터 백업** → 팀원에게 JSON 전달 → 팀원이 **📤 가져오기**.

### Q. Pro 버전은 언제?
A. 대기자 명단 100명 도달 시 개발 시작. 월 ₩19,000에 API 키 없이 50회 협업 포함 예정. [대기자 등록 →](https://jwaytools.com/paperclip/#pro-waitlist)

### Q. 커스텀 템플릿 만들기
A. ⚙️ 설정 → **📦 현재 팀을 템플릿으로 저장** → JSON 다운로드 → 공유/판매 가능.

## 🔧 문제 해결

### API Error 400 (invalid_request_error)
- API 키 확인 (`sk-ant-api03-...` 형식)
- Anthropic 콘솔에서 크레딧 잔액 확인
- 이모지 surrogate 문제 → 자동 처리됨 (최신 버전)

### API Error 429 (rate_limit_error)
- 분당 토큰 제한 초과
- 해결: 에이전트 간 지연 15초로 증가
- 또는: 팀 크기 축소

### 에이전트가 무한 루프로 돌아감
- 시스템에 3회 재시도 제한 내장
- 그래도 문제 시 ⏹ 중단 버튼
- 또는 에이전트 상태 🔄 리셋

### 아티팩트가 생성되지 않음
- 프롬프트에 "artifact 액션으로 실제 결과물 생성" 명시
- 모델을 Haiku보다 큰 것으로 변경
- max_tokens가 자동으로 8192로 설정되어 있어야 함

### 랜딩페이지가 업데이트 안 됨
- 브라우저 캐시 문제 → `Ctrl+F5`
- GitHub Pages CDN 캐시 → 10분 대기
